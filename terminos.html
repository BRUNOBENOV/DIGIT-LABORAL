Finalidad

La demostración permite conocer la interfaz y los flujos previstos para Digit Laboral. Los datos, cálculos, documentos, artículos y respuestas mostrados tienen carácter ilustrativo.

Sin asesoramiento jurídico ni contable

Los resultados no sustituyen el análisis de un profesional ni la verificación de normas, parámetros, convenios, resoluciones o circunstancias aplicables a cada caso.

Uso permitido

Usá únicamente datos ficticios. Queda prohibido introducir información confidencial o utilizar esta demostración como sistema productivo.

Disponibilidad

El sitio temporal puede cambiar, interrumpirse o eliminarse durante el desarrollo. Las funciones productivas dependerán del servidor, la base de datos y la configuración contratada.

Propiedad del proyecto

Digit Laboral es una iniciativa asociada a Victor's Contabilidad. La identidad visual y el software deberán ser utilizados conforme a las autorizaciones del titular.
