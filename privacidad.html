Política de privacidad de la demostración

Última actualización: 31 de julio de 2026.

Esta versión pública de Digit Laboral es una demostración técnica. No está destinada a recibir ni conservar información real de clientes, empresas, trabajadores o terceros.

Datos almacenados en la demostración

Los datos ficticios que ingreses se guardan localmente en el navegador del dispositivo mediante almacenamiento web. No constituyen una base de datos productiva ni un respaldo empresarial.

Información que no debe cargarse

No cargues cédulas reales, salarios reales, contratos, documentos internos, contraseñas, datos bancarios, información médica ni ningún dato confidencial.

Contacto comercial

Para solicitar una demostración guiada o consultar la versión productiva, comunicate con Victor's Contabilidad al 0983 102 220.

Versión productiva

La versión productiva deberá contar con autenticación real, base de datos segura, HTTPS, control de permisos, respaldo, auditoría y documentos contractuales de privacidad adaptados a la operación efectiva.
