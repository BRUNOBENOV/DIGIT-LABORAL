# Digit Laboral

Plataforma de gestión laboral en la nube para estudios contables paraguayos.

## Sitio comercial

El archivo `index.html` contiene la página pública de venta y `app-demo.html` una demostración navegable. GitHub Actions publica automáticamente estos archivos en GitHub Pages.

## Aplicación

La aplicación FastAPI mantiene empresas, funcionarios, solicitudes, liquidaciones, vacaciones, aguinaldo, documentos, usuarios, auditoría y biblioteca jurídica.

## Publicación de la aplicación y base de datos

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/BRUNOBENOV/DIGIT-LABORAL)

Durante el despliegue, usá un correo real para `ADMIN_EMAIL` y una contraseña nueva y exclusiva para `ADMIN_PASSWORD`. No publiques credenciales en el repositorio.

## Alcance de la demostración

Los datos de la vista previa son ficticios. Los cálculos y contenidos jurídicos requieren revisión profesional antes de utilizarse en casos reales.
