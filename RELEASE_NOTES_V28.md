# Digit Laboral 2.6.28 — Visibilidad del Centro de Informes

Se corrige la navegación para que el rol `empresa` pueda acceder al Centro de Informes desde el menú lateral.

- El informe se limita a las empresas autorizadas del usuario.
- Se mantiene restringido el listado de exámenes médicos.
- Cumplimiento REI/REOP y Auditoría no se exponen en el menú de empresa.
- Se añade una prueba de integración para la visibilidad y el catálogo permitido.
