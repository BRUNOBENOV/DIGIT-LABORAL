# Nota de migración del sistema visual

El documento histórico v2.6.4 fue reemplazado por la especificación consolidada **v2.6.48**.

Consultar: [Sistema visual DIGIT-LABORAL v2.6.48](VISUAL_SYSTEM_V2648.md).

La navegación global ahora se concentra en la barra lateral de cinco áreas. Los módulos mantienen únicamente navegación contextual cuando aporta subsecciones propias. Los tokens corporativos, los componentes compartidos, los criterios responsive y los límites funcionales están documentados en la nueva especificación.

Este archivo se conserva como punto de compatibilidad para referencias históricas al documento v2.6.4.
