# Lista de seguridad antes de usar datos reales

- Cambiar las cinco contraseñas de demostración.
- Generar una clave secreta larga y aleatoria.
- Usar PostgreSQL, no SQLite, en producción.
- Forzar HTTPS y cookies seguras.
- Configurar copias de seguridad automáticas y probar la restauración.
- Guardar documentos en almacenamiento privado persistente.
- Limitar tamaño y formatos de archivos.
- Añadir protección CSRF y límite de intentos de inicio de sesión.
- Implementar recuperación de contraseña mediante correo verificado.
- Revisar permisos de cada rol.
- Mantener registro de auditoría.
- Crear una política de retención y eliminación de datos.
- Realizar una revisión de seguridad antes del lanzamiento comercial.
